# The connection between the site and the engine

**Track A owns this document. Track B reads it and builds against it.**

Written 18 August 2026, session A1, from the running engine rather than designed
on paper. Every shape below was produced by calling it.

---

## 1. The short version for Track B

**The site never runs Python and never touches the engine's code.** It sends a
file over the internet and gets JSON back. Two calls exist:

| Call | Question it answers | Changes anything? |
|---|---|---|
| `POST /inspect` | **What is hidden in this?** | No. Read only |
| `POST /clean` | **Take it out and give it back** | Returns a new file |

**Both take the same input.** Pasted text is just a file called `paste.txt`.
There is no separate text path to build.

---

## 2. The request

```json
{
  "file": "<the file's bytes, base64 encoded>",
  "name": "report.docx"
}
```

**`name` matters.** The extension is what tells the engine whether it is looking
at text, an image or a document. Send the user's real filename. For pasted text,
send `paste.txt`.

**Base64 is just a way of putting any file into a text field.** Browsers do it in
one line.

---

## 3. What `/inspect` gives back, and why it is the product

This is the call that powers the screen a visitor sees before signing up.

```json
{
  "ok": true,
  "kind": "text",
  "suspicious": true,
  "report": {
    "length": 63,
    "suspicious_total": 3,
    "hits": [
      {
        "codepoint": "U+200B",
        "label": "U+200B ZERO WIDTH SPACE (Cf)",
        "count": 1,
        "kind": "zwj_family",
        "confidence": "probable",
        "sample_offsets": [20]
      }
    ]
  }
}
```

**`sample_offsets` is the gold.** It is the exact position of each hidden
character in the text. **That is how the site highlights them in place** rather
than just printing a number, and it is the difference between "we found 3 things"
and "there, and there, and there."

**`label` is already human readable.** Do not invent your own names for these.

**`confidence` exists and must be shown.** Values seen: `probable`,
`informational`. Not everything found is certainly a watermark.

**For a file rather than text, `kind` is `image` or `container`** and the report
names what was found, for example `JPEG APP1: c2pa, OpenAI` or
`docProps/core.xml: ai:Generated by`.

---

## 4. What `/clean` gives back

```json
{
  "ok": true,
  "kind": "text",
  "cleaned": "<the cleaned file's bytes, base64 encoded>",
  "report": {
    "stats": {
      "input_length": 63,
      "output_length": 60,
      "removed": { "U+200B ZERO WIDTH SPACE (Cf)": 1 },
      "replaced": {},
      "removed_count": 3,
      "replaced_count": 0
    }
  }
}
```

**Removed and replaced are separate numbers and both must be shown.** Some
characters are deleted, some are swapped for an ordinary space. **A swap does not
change the length**, so a naive "characters removed" figure will not match the
size change and will look broken. This already caught the assistant once.

**For files, the report is a list of plain English actions**, for example
`drop chunk tEXt` or `scrub docProps/core.xml field dc:creator`, plus
`still_has_c2pa` and `still_has_ai_metadata`, which are the honest verdict.

---

## 5. Failures

```json
{ "ok": false, "error": "missing string field 'file' (base64-encoded bytes)" }
```

**`ok` is the only thing to branch on.** Never show the raw `error` text to a
user. **Map it to one of our own written messages**, which is the practice that
survived from `04` entry 15 and is the fix for the defect still open as `06`
row 13.

**One trap that is not a failure.** The engine's command line tools **exit with a
non-zero code when they find something**, the way a scanner does. Over HTTP this
does not apply, but if anything ever calls the engine directly, **a non-zero exit
means marks were found, not that something broke.**

---

## 6. Where it runs

**On Vercel, beside the site. There is no second hosting company.** `04` entry 27.

**How, precisely.** The engine ships its own web server, `service/scripts/server.py`,
which is what produced every example above and is what to use when developing
locally:

```bash
cd ~/un-claude/engine && python3 service/scripts/server.py --port 8765
```

**In production it is a thin Vercel function that calls the engine's Python
directly**, rather than that server running permanently. Same shapes, same field
names, deliberately, so that anything built against the local server works
unchanged in production.

**It supports a shared password (`--api-key`) and production will use one**, so
that only our own site can call it.

## 7. Usage recording, which Track B must not build

**The engine already returns the numbers pricing will need**, and Track A wires
the recording. Track B does not.

| Number | Where it comes from |
|---|---|
| Size of text in | `report.length` or `stats.input_length` |
| Size of file in | The bytes sent |
| How much was found | `suspicious_total`, `removed_count`, `replaced_count` |
| Layer B model cost | Not built yet. Session A2 |

**Track B's job on this is different and comes later, in B2:** enforcing the free
cap and showing a balance. **Not metering, and not pricing.** Pricing is
undecided and has its own session. `06` row 18.

## 9. Layer B over HTTP

**One extra option on the call you already make.**

```json
{ "file": "<base64>", "name": "paste.txt", "options": { "layer_b": true } }
```

**Leave it out and nothing changes:** layer A only, instant, no model call, no
cost. **That is the free path a signed out visitor gets.**

**Turn it on** and the text is rewritten first, then layer A runs on the result.
Measured end to end through the server: **6.4 seconds for 566 words.**

The response gains a `layer_b` block inside `report`:

```json
"layer_b": {
  "model": "mistral/mistral-small",
  "mode": "rewritten",
  "verified": false,
  "note": "Layer B is best effort. No public detector exists for any vendor's
           text watermark, so nobody can verify removal, including us."
}
```

**`verified` is always `false` and the note always ships.** `04` entry 23. The
interface must not present a layer B result with the confidence of the other two.

### Configured entirely by environment variable

| Variable | Value in use |
|---|---|
| `WATERMARKS_REWRITE_BACKEND` | `openai-compatible` |
| `WATERMARKS_REWRITE_BASE_URL` | `https://ai-gateway.vercel.sh` (no `/v1`, the code appends it) |
| `WATERMARKS_REWRITE_MODEL` | `mistral/mistral-small` |
| `WATERMARKS_REWRITE_API_KEY` | **Secret.** Never in the repository |

**The model is one setting, deliberately.** If a vendor starts watermarking its
own output, swapping it is a one line change. `06` row 29.

**It must never be an Anthropic or Google model.** Rewriting Claude text with
Claude re-applies the watermark at full strength rather than removing it.
